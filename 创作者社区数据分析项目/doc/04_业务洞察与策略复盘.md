## 1.2 客观数据洞察

### 洞察 1：新人留存的核心问题不是“首次发布”，而是首篇后的持续发布

**对应证据：E1、E2、E3。**

- 合格新人达到 12,862 人，但 D7 再次发布留存率只有 2.01%。
- D14 累计再一次发布留存率为 7.47%。D14 高于 D7 是因为 D14 使用更长的累计观察窗，表示首篇后两周内出现过再次发布的新人比例，不代表第 14 天当天活跃率。
- 在可评估新人中，D7 流失停更组人数为 12,603 人，留存成功组为 259 人，样本规模本身说明“首篇后没有形成第二次创作”是主要供给现象。

这表明当前分析问题应定位为“首篇后二次创作机制”，而不是简单统计注册量或发布量。该结论是描述性事实，不说明为什么新人没有再次发布。

### 洞察 2：首篇曝光、点击和互动与 D7 留存存在明显同向差异

**对应证据：E3。**

- D7 留存成功组首篇曝光中位数为 3,828，流失停更组为 355，留存成功组明显更高。
- 留存成功组首篇 CTR 中位数为 3.92%，流失停更组为 2.99%。
- 留存成功组首篇互动率中位数为 49.47%，流失停更组为 45.00%。
- 留存成功组首篇后 7 日发布篇数中位数为 2，流失停更组为 1。

这些是相关性发现。它们说明首篇早期反馈、内容点击表现和持续发布在同一个人群中共同出现，但不能证明“提高曝光一定提高留存”。同样不能排除内容质量、赛道、账号基础、发布时间或创作者原始意愿等共同因素。

### 洞察 3：多数创作者位于低价值流失群体，潜力新人只占较小规模

**对应证据：E4。**

- 低价值流失群体为 11,802 人，是当前最大群体。
- 腰部稳定 3,648 人，头部高收益 2,653 人。
- 潜力新人 1,523 人。

这说明供给侧并不是“少量长尾加成熟创作者”的简单结构，低活跃、低流量效率和低变现价值会在同一人群里叠加。三维分层来自相对分位规则，描述的是当前快照中的相对位置，不代表各群体的因果潜力。

### 洞察 4：各赛道的流量规模、点击效率与变现效率并不同步

**对应证据：E5。**

| 赛道 | 创作者数 | 有效笔记数 | 曝光份额 | CTR | 单篇已结算创作者收益 | 新人 D7 留存 | 新人 D14 留存 | 观察 |
|---|---:|---:|---:|---:|---:|---:|---:|---|
| 旅行 | 4,511 | 12,366 | 20.68% | 5.298% | ￥760.90 | 2.043% | 7.872% | 曝光与收益份额均较高 |
| 美食 | 5,529 | 14,293 | 17.27% | 5.346% | ￥523.26 | 2.185% | 7.512% | 创作者和笔记数量最多，但单篇收益低于旅行、穿搭、家居 |
| 穿搭 | 4,168 | 10,792 | 16.67% | 5.289% | ￥714.54 | 1.558% | 6.338% | 单篇收益较高，但当前 D7 留存最低 |
| 美妆 | 3,771 | 9,693 | 12.52% | 5.174% | ￥564.11 | 2.027% | 7.752% | 各项处于中间水平 |
| 家居 | 2,891 | 7,528 | 12.41% | 5.373% | ￥759.21 | 2.209% | 8.911% | CTR 和 D14 留存均为最高，单篇收益接近旅行 |
| 其他 | 2,940 | 7,454 | 9.80% | 5.215% | ￥614.27 | 2.506% | 7.831% | D7 留存最高，但“其他”类目不可直接作为明确业务赛道 |
| 母婴 | 2,365 | 5,642 | 6.64% | 5.178% | ￥545.75 | 1.775% | 7.002% | 规模较小，留存和效率均不突出 |
| 数码 | 2,429 | 5,614 | 4.02% | 5.133% | ￥281.87 | 1.731% | 6.442% | 曝光份额、CTR 和单篇创作者收益均处于低位 |

赛道差异说明“流量规模”不能直接替代“流量效率”和“变现效率”。旅行赛道流量与收益份额都较高，家居赛道用较低曝光份额实现较高 CTR 和单篇收益，数码赛道当前曝光份额和单篇收益均较低。该比较是横截面描述，未控制内容质量、商品结构、创作者层级和活动影响。

## 1.3 供给侧核心问题

### 问题一：首篇后缺少可测量的二次创作触发点

**依据：E2、E3。**

大量新人停在首篇之后，现有结果只能证明“首篇后是否再次发布”是当前最明显的分群变量。不能直接把停更归因于平台体验。

### 问题二：新人的早期流量反馈与持续创作同时偏弱

**依据：E3。**

留存成功组的曝光、CTR、互动率和首周发布篇数均更高。当前无法判断是“获得反馈后继续发布”，还是“本来更有创作能力的人既获得较高反馈又继续发布”。

### 问题三：长尾供给规模大，但创作稳定性和变现效率低

**依据：E4。**

低价值流失群体数量远高于潜力新人、腰部稳定和头部高收益。需要区分“没有近期发布”“有发布但流量效率低”“有流量但变现低”三种状态，不能只依赖一个标签。

### 问题四：赛道运营需要按“流量—效率—留存”组合判断

**依据：E5。**

旅行、美食、穿搭的曝光规模较大，并不能推导出所有赛道都应增加流量。家居当前 CTR、单篇收益和 D14 留存表现较好，数码当前多项指标偏弱。是否存在资源错配仍需控制内容质量、商品和用户需求后验证。

## 1.4 观测与猜想的边界

| 类型 | 可以表达的结论 | 不能直接表达的内容 |
|---|---|---|
| 客观观测 | D7 留存为 2.01%，D14 累计留存为 7.47%；留存成功组首篇曝光和互动中位数更高 | 提高曝光一定会提高留存 |
| 客观观测 | 低价值流失群体人数最多；不同赛道指标有差异 | 低价值群体都是运营可唤醒人群 |
| 客观观测 | 数码单篇已结算收益低于旅行、穿搭、家居等赛道 | 调整商业策略一定能提升数码收益 |
| 猜想的起点 | 首篇正向反馈可能降低停更概率 | 首篇曝光对留存具有已证实的因果效应 |
| 猜想的起点 | 潜力新人可能对二次发布任务更敏感 | 潜力新人策略一定具备正的投入产出比 |

# 二、分角色落地业务优化策略

以下策略均为待验证假设。策略执行前后必须使用同一 `metric_version` 的 DWS 指标，实验外不得直接改写历史口径。

## 2.1 创作者运营侧策略

### 策略 O1：潜力新人“首周三篇”成长路径

| 项目 | 内容 |
|---|---|
| 数据依据 | E3、E4：D7 留存成功组首周发布篇数中位数 2；潜力新人 1,523 人 |
| 目标人群 | `creator_segment_3d='潜力新人'`，且近 28 日有有效发布 |
| 执行动作 | 首篇后 24 小时推送第二篇选题建议；第 3 天反馈首篇 CTR/互动和可改进项；第 5 天提供同赛道低额度曝光券；第 7 天触发第三篇任务 |
| 预期业务收益 | 提高 D7/D14 再发文留存、首周发布篇数和有效创作者供给 |
| 主指标 | D7 留存率、D14 累计留存率、首篇后 7 日发布篇数 |
| 护栏指标 | 负反馈率、内容质量分、低质重复发布率、单篇已结算收益、用户停留和完读率 |
| 风险与负面可能 | 潜力新人来自相对分位，可能只是流量自然回升；任务奖励可能诱发凑数内容；流量券可能挤压其他创作者 |
| DWS 监控 | `dws_creator_lifecycle_df` 观察留存；`dws_creator_segment_df` 观察分层迁移；`dws_new_creator_retention_detail_df` 控制首篇表现分群；`dws_note_traffic_conversion_df` 看内容护栏 |

**适用边界：** 首篇内容质量不达标或存在硬/软异常的创作者不应直接进入流量券组。策略效果以实验增量判断，不以潜力新人整体留存和平台均值比较。

### 策略 O2：7 天高流失新人分层触达

| 项目 | 内容 |
|---|---|
| 数据依据 | E2、E3：D7 流失停更新人 12,603 人；该组首篇曝光、CTR、互动率和首周发布篇数中位数均低于留存组 |
| 目标人群 | `retained_7d=0` 的已成熟新人；优先选择首篇表现位于低曝光或低 CTR 分位，且无硬异常的账号 |
| 执行动作 | 进行一次内容诊断；提供同赛道优秀案例拆解；推送第二篇模板；设置可选的 7 日创作提醒；不直接承诺流量或收入 |
| 预期业务收益 | 增加第二次有效发布，改善 D7/D14 留存和后续有效供给 |
| 主指标 | 干预后 7 日再发文率、D14 累计留存率 |
| 护栏指标 | 消息打扰/负反馈、账号取关、低质内容比例、审核拒绝率、单篇曝光效率 |
| 风险与负面可能 | 大规模触达带来打扰；低活跃用户可能是结构性退出；低 CTR 可能来自内容质量而非分发 |
| DWS 监控 | `dws_creator_lifecycle_df`、`dws_new_creator_retention_detail_df`、`dws_note_traffic_conversion_df` |

**适用边界：** 只对账号状态正常、观察窗成熟且核心指标完整的新人触达。封禁、注销和测试账号不进入运营名单。

### 策略 O3：低价值流失群体先诊断、后分层召回

| 项目 | 内容 |
|---|---|
| 数据依据 | E4：低价值流失群体 11,802 人，人数最多；E3：7 天停更群体发布频次低于留存组 |
| 目标人群 | `creator_segment_3d='低价值流失群体'`，先拆分为近期无发布、低流量效率、低变现价值三类 |
| 执行动作 | 对近期无发布但历史有内容者做低成本召回；对仍有发布但流量低者做标签/关键词和内容结构诊断；对无响应者停止高频触达 |
| 预期业务收益 | 以较低成本识别可召回人群，减少一次性流失和无效内容供给 |
| 主指标 | 召回后 14 日再发文率、D14 留存率、活跃创作者数 |
| 护栏指标 | 触达退订、举报率、低质草稿/重复内容、单用户触达成本、审核拒绝 |
| 风险与负面可能 | 低价值群体内部异质性高，统一召回可能浪费预算；历史低价值不等于未来无价值 |
| DWS 监控 | `dws_creator_lifecycle_df`、`dws_creator_segment_df`、`creator_three_dim_segments.csv` 对应的 DWS 创作者分层结果 |

**适用边界：** 不在三类画像未拆开前做全量补流量或全量现金激励。策略预算只用于有近期创作信号、内容质量达标且可联系的用户。

## 2.2 产品与分发算法侧策略

### 策略 P1：新人首篇受控探索流量

| 项目 | 内容 |
|---|---|
| 数据依据 | E3：D7 留存成功组首篇曝光中位数 3,828，流失组 355；CTR 和互动率也更高 |
| 目标人群 | 通过硬/软异常校验的新人首篇，按首篇 CTR 分群、赛道、渠道进行分层抽样 |
| 执行动作 | 在推荐排序中设置小比例探索流量，对内容质量达标、前段点击和负反馈未触发红线的首篇逐步扩量；达到护栏后再考虑第二篇同池 |
| 预期业务收益 | 提升首篇获得最小反馈的概率，观察是否带动 D7/D14 再发文 |
| 主指标 | 实验组相对对照组的 D7、D14 留存率增量；第二次有效发布率 |
| 护栏指标 | 负反馈率、举报率、用户完读率、曝光分配基尼、存量创作者曝光损失、广告 RPM |
| 风险与负面可能 | 曝光与留存不是已确认因果；只增加曝光可能放大低质内容；挤占其他内容流量；看到流量后创作者仍可能停更 |
| DWS 监控 | `dws_note_traffic_conversion_df` 看 CTR、完读率和负反馈；`dws_creator_lifecycle_df` 看 D7/D14；`dws_track_performance_df` 看赛道流量份额 |

**AB 验证要求：** 必须随机分组并设置对照组；先小流量灰度；不能以“历史上留存好的人曝光更高”直接推导规则上线。

### 策略 P2：首篇质量反馈与二次发布入口

| 项目 | 内容 |
|---|---|
| 数据依据 | E3：留存组首篇 CTR、互动率和首周发布篇数更高 |
| 目标人群 | 首篇发布且无硬异常的新人 |
| 执行动作 | 在发布后展示首篇 CTR、完读、互动和负反馈摘要；给出第二篇选题方向；将“继续发布”入口前置 |
| 预期业务收益 | 提高首篇后的第二次有效发布和 D7 留存 |
| 主指标 | D7 再发文率、首篇后 7 日发布篇数 |
| 护栏指标 | 完读率、负反馈率、内容质量分、重复/模板化内容占比 |
| 风险与负面可能 | 数据反馈可能让低表现用户更早放弃；反馈若以曝光绝对值为主，可能诱导追热点和低质内容 |
| DWS 监控 | `dws_new_creator_retention_detail_df` 按首篇表现分群；`dws_note_traffic_conversion_df` 看内容质量；`dws_creator_lifecycle_df` 看再发布 |

**适用边界：** 反馈文案不能暗示平台承诺流量；低 CTR 不能直接解释为内容质量差，应配合赛道和曝光人群解释。

## 2.3 商业化变现侧策略

### 策略 C1：旅行赛道做规模化但保留质量门槛

| 项目 | 内容 |
|---|---|
| 数据依据 | E5：旅行曝光份额 20.68%、收益份额 20.90%、单篇已结算创作者收益 ￥760.90 |
| 目标人群 | 旅行赛道中 CTR、完读率和负反馈达标的活跃创作者 |
| 执行动作 | 提供品牌合作与商品组合建议；对高质量内容开放商业化任务；保持自然内容与商业内容的配比 |
| 预期业务收益 | 提升已结算创作者收益、商业内容覆盖和单篇变现效率 |
| 主指标 | 单篇已结算收益、商业化覆盖人数、收益份额 |
| 护栏指标 | 负反馈率、审核拒绝率、退货/退款、用户完读率、自然流量份额 |
| 风险与负面可能 | 高频商业内容可能稀释自然体验；曝光规模高不等于每个创作者都适合带货 |
| DWS 监控 | `dws_track_performance_df`、`dws_note_traffic_conversion_df`、`dws_creator_segment_df` |

**适用边界：** 当前只有创作者已结算收益，没有平台成本和商品毛利，不能据此判断平台利润最优。

### 策略 C2：家居赛道做“高点击内容 → 商品匹配”验证

| 项目 | 内容 |
|---|---|
| 数据依据 | E5：家居 CTR 5.373%、单篇已结算收益 ￥759.21、D14 留存 8.911%，但曝光份额为 12.41% |
| 目标人群 | 家居赛道中点击效率和内容质量达标的创作者 |
| 执行动作 | 做商品类目与内容主题匹配实验；对高 CTR 内容增加合规商品组件；优先选择退货、负反馈可控的商品 |
| 预期业务收益 | 在不显著增加流量供给的情况下提高商品点击率、成交转化和单篇收益 |
| 主指标 | 商品点击率、带货成交转化率、单篇已结算收益 |
| 护栏指标 | 负反馈率、退款率、GMV 冲回率、自然 CTR、创作者内容质量 |
| 风险与负面可能 | 高点击不等于高购买；商品匹配可能损伤内容可信度；平台补贴可能制造短期收入 |
| DWS 监控 | `dws_track_performance_df`、`dws_note_traffic_conversion_df`、`dws_creator_lifecycle_df` |

**适用边界：** 家居当前较高的 D14 留存和 CTR 不能证明增加商业组件不会伤害留存，必须用小流量 AB 验证。

### 策略 C3：数码赛道先验证内容—商品适配，不直接扩量补贴

| 项目 | 内容 |
|---|---|
| 数据依据 | E5：数码曝光份额 4.02%、CTR 5.133%、单篇已结算收益 ￥281.87、D7 留存 1.731%，多项指标位于比较低位 |
| 目标人群 | 数码赛道中有商品点击但成交低、或高 CTR 低商品点击的创作者 |
| 执行动作 | 拆解商品选品、价格带、详情页承接和内容结构；对不同选品进行小范围商业 AB；不适合商品化的内容继续自然分发 |
| 预期业务收益 | 区分“流量不足”“商品不匹配”“成交承接差”，提高有效商品点击和单篇收益 |
| 主指标 | 商品点击率、成交转化率、单篇已结算收益 |
| 护栏指标 | 退款率、负反馈率、完读率、广告 RPM、自然内容占比 |
| 风险与负面可能 | 数码客单价和决策链路更长，短期转化可能偏低；盲目加流量可能只放大低效曝光 |
| DWS 监控 | `dws_track_performance_df`、`dws_note_traffic_conversion_df`、`dws_creator_segment_df` |

**适用边界：** 缺少商品成本、平台分成成本和履约成本，无法判断该赛道是否真正亏损或值得补贴。

### 策略 C4：美食赛道关注商品选择而非单纯增加内容量

| 项目 | 内容 |
|---|---|
| 数据依据 | E5：美食活跃创作者 5,529 人、有效笔记 14,293 篇，均为各赛道最高；单篇已结算收益 ￥523.26，低于旅行、穿搭和家居 |
| 目标人群 | 美食赛道内有商品挂载但转化或结算表现偏低的创作者 |
| 执行动作 | 测试食品生鲜等高适配商品的挂载组合；对比不同价格带和内容形式；不把“增加发文量”作为唯一手段 |
| 预期业务收益 | 在现有内容供给规模下提高商品点击、成交和单篇收益 |
| 主指标 | 商品点击率、成交转化率、单篇已结算收益 |
| 护栏指标 | 退款率、负反馈率、内容质量、笔记同质化程度 |
| 风险与负面可能 | 食品类目价格敏感、退款和履约因素可能影响收益；推荐过多商品可能损伤内容体验 |
| DWS 监控 | `dws_track_performance_df`、`dws_note_traffic_conversion_df` |

**适用边界：** “其他”类目当前 D7 留存较高，但定义过宽，不应作为独立赛道直接制定预算；需要先拆成可运营标签。

# 三、指标监控与 AB 实验评估方案

## 3.1 实验前基线

| 基线环节 | DWS 表 | 使用方式 |
|---|---|---|
| 新人身份与成熟度 | `dws_creator_lifecycle_df` | 只纳入已成熟、`retained_7d_eligible=1` 或 `retained_14d_eligible=1` 的新人 |
| 首篇表现分群 | `dws_new_creator_retention_detail_df` | 按 `first_note_segment`、赛道、首月检查组间基线，避免随机分组后分布失衡 |
| 三维分层 | `dws_creator_segment_df` 及创作者三维分层表 | 检查潜力新人、腰部、头部、低价值群体的实验覆盖和样本量 |
| 赛道结构 | `dws_track_performance_df` | 按赛道分层随机，防止旅行或美食等大流量赛道主导整体结果 |
| 笔记护栏 | `dws_note_traffic_conversion_df` | 固化 CTR、完读、互动、商品点击、负反馈和收益基线 |
| 历史口径 | `creator_growth_attribution_analysis.py` 输出的 `metric_version` | 实验前后必须复用同一清洗与留存口径 |

**分层随机建议：** 按首篇表现分群、内容赛道、创作者层级和渠道分层；先随机再触达，不能按“是否响应”事后分组。首篇表现差的组可以设置最小样本和单独分析，但不应被剔除。

## 3.2 指标优先级

### 新人扶持实验

| 指标层级 | 指标 | 定义边界 |
|---|---|---|
| 主指标 | D7 留存率、D14 累计留存率 | 首篇有效公开笔记后是否再次发布，不用登录活跃替代 |
| 核心过程指标 | 首篇后 7 日发布篇数、第二次有效发布率 | 只统计 `is_core_eligible=1` 的公开笔记 |
| 内容质量指标 | 内容质量分、完读率、负反馈率 | 避免用低质内容冲留存 |
| 商业护栏 | 单篇已结算创作者收益、广告 RPM、退款率 | 收入只取结算成功记录 |
| 生态护栏 | 曝光份额、创作者层级分布、赛道流量份额 | 防止扶持流量过度集中 |

### 流量分发实验

| 指标层级 | 指标 | 约束 |
|---|---|---|
| 主指标 | D7/D14 留存、首篇后再次发布 | 不是首篇笔记最终 GMV |
| 点击指标 | CTR、有效点击 UV | 曝光和点击使用同一 7 日窗口 |
| 内容体验 | 完读率、负反馈率、举报率 | 负反馈不能被曝光增长掩盖 |
| 供给指标 | 首篇后发布篇数、有效创作者数 | 不把任务提交或草稿当发布 |
| 存量影响 | 非实验创作者曝光、人均曝光、赛道流量份额 | 检查对现有供给的挤压 |

### 商业化实验

| 指标层级 | 指标 | 约束 |
|---|---|---|
| 主指标 | 商品点击率、成交转化率、单篇已结算收益 | 成交转化用付费买家 UV / 商品点击 UV |
| 规模指标 | 净 GMV、商业化覆盖人数 | GMV 不能替代平台利润 |
| 质量护栏 | 退款率、负反馈率、完读率、自然 CTR | 防止商业内容破坏消费体验 |
| 成本门槛 | 平台成本、商品成本、结算成本 | 当前数据集缺失，未补齐前不能判断 ROI |

## 3.3 主要风险与规避

| 风险 | 可能后果 | 规避方式 |
|---|---|---|
| 样本选择偏差 | 只给本来更有能力的新人扶持，实验组天然更高 | 先随机、后触达；保留 ITT 和实际触达两种结果 |
| 口径漂移 | 实验组和对照组使用不同留存或收益口径 | 固定 `metric_version`、特征截止日和数据提取日 |
| 流量互相挤占 | 实验组曝光上升来自对照组损失，平台总量不变 | 增加对照组曝光损失、全局流量分配和赛道份额护栏 |
| 内容质量混杂 | 曝光增加带来互动，内容质量却下降 | 同时看完读、负反馈、举报和内容质量分 |
| 活动/季节影响 | 节假日或平台活动改变 D7/D14 | 同期随机、保留活动 ID 和日期控制 |
| 创作者同时进入多个实验 | 策略重叠导致无法归因 | 以 `creator_id` 做互斥；实验登记表记录组别 |
| 事后筛选显著群体 | 针对提示性细分过度解释 | 预注册主次指标和分层；报告置信区间和多重比较风险 |
| 收益口径错误 | 把 GMV 当创作者收益或毛利 | 收益只取已结算记录；毛利等待成本字段 |
| 统计显著但业务不显著 | 小幅显著没有覆盖运营成本 | 预设最小可检测效应和成本门槛，不只看 p 值 |

## 3.4 全量推广判断

策略同时满足以下条件才进入扩量评审：

1. 预注册主指标在实验组和随机对照之间出现稳定的正向增量，且置信区间与预先定义的最小可检测效应一致。
2. D7、D14 和首周发布等过程指标方向一致；不能只出现一个孤立指标改善。
3. 负反馈、内容质量、退款、流量集中度和存量创作者曝光等护栏未出现不可接受的恶化。
4. 结果在主要赛道、渠道和首篇表现分群中不存在方向相反的严重异质性，或已明确限定适用人群。
5. 商业策略在补充成本数据后能够证明单位扶持成本可被可归因收益覆盖；未补齐成本前不得以创作者收益直接代替 ROI。
6. 至少复现一次同期或后续批次，避免单一时间窗口的偶然结果。

# 四、项目局限性 & 可优化方向

## 4.1 当前数据集的局限

1. **没有成本字段。** 现有字段可以计算已结算创作者广告分成和佣金，但没有平台分成成本、商品成本、履约成本。因此不能严格计算平台毛利，也不能做真正的 ROI 排序。
2. **数据为模拟数据。** 数据用于验证分析链路、口径和代码实现，不代表真实公司的业务规模；所有绝对值只能作为方法示例。
3. **未执行真实实验。** 当前分组和分层都来自观测数据，不能把留存成功组和流失组的差异解释为因果。
4. **缺少用户级事件明细。** 当前基础表是笔记粒度的行为汇总，无法重新构造完整曝光事件、点击旅程和真实用户级去重；UV/PV 口径只能在既有汇总基础上做后置分析。
5. **缺少内容和治理上下文。** 没有完整正文、图片质量、审核原因、创作成本、创作者动机和账号历史，难以判断“低曝光低留存”是分发问题还是内容/意愿问题。

## 4.2 数据治理局限

1. 互动量 12 倍、关注转化 20%、负反馈 5% 和阅读 1 小时属于当前项目的经验护栏，尚未基于真实线上过去 180 天的 P99.5 分布重新校准。
2. 账号风险维表没有真实线上确认结果，测试号、内部号和作弊号的识别主要依赖账号状态与模拟异常规则。
3. DWD 硬异常不影响原始行保留，但阈值调整会改变 `is_core_eligible` 人群，从而影响留存、赛道和收益的绝对值。
4. 模拟数据没有真实重复上报和撤回事件，因此代码虽然实现了标记逻辑，当前数据中的重复上报数仍为 0；不能因为本次为 0 就省略线上监控。

## 4.3 分析层面的局限

### 例一：首篇曝光与流失的混淆

当前观测显示，7 天留存成功组的首篇曝光中位数高于流失组，但这不能证明“低曝光导致流失”。至少存在三种竞争解释：

- 首篇曝光较高带来正向反馈，进而提高继续创作概率。
- 内容质量和选题能力同时提高曝光、点击和留存。
- 本来更有创作意愿的创作者更愿意持续发布，平台算法也给了更高曝光。

现有横截面结果不能区分这些机制。

### 例二：三维分层是相对位置，不是因果人群

“潜力新人”由活跃度、流量效率和变现价值的分位数组合得到，代表当前快照中的相对画像。分位数阈值变化、赛道变化或观察窗口变化都可能改变人群。

### 例三：赛道差异包含结构混杂

旅行曝光份额高、家居 CTR 和单篇收益高，但赛道之间的内容质量、商业供给、用户需求、竞争强度和算法策略不同。当前不能把赛道差异直接理解为赛道本身带来的收入差异。

### 例四：留存定义本身是高敏感口径

本项目 D7/D14 指首篇后累计再次发布有效公开笔记。改成登录留存、第 7/14 天当天活跃、以注册日为起点，都会产生不同数值，不能跨口径比较。

## 4.4 拿到真实生产数据后的增强方向

| 方向 | 可补充数据 / 方法 | 目标 |
|---|---|---|
| 因果探索 | 随机实验、倾向得分匹配、双重差分、断点回归 | 验证首篇流量、内容和扶持对留存的增量 |
| 留存机制 | 日级发布、曝光、点击、互动事件 | 区分首篇反馈、二次创作和停更的时间顺序 |
| 内容质量 | 多模态内容质量、审核原因、负反馈、举报原因 | 判断低曝光是内容问题还是分发问题 |
| 创作者动机 | 问卷、草稿行为、创作时长、创作任务 | 区分能力不足、意愿不足和激励不足 |
| 商业价值 | 平台净收入、商品成本、佣金成本、履约成本和退款 | 从创作者收益扩展到平台贡献毛利和 ROI |
| 分发公平 | 算法版本、流量池、实验组、用户兴趣匹配 | 评估统一曝光、质量加权和赛道适配 |
| 长周期效果 | 90/180 天留存、回流、生命周期分层迁移 | 判断短期留存提升是否持续 |
| 异质性分析 | 分赛道、渠道、城市层级、首篇表现的交互分析 | 识别策略适用和不适用边界 |

**方法建议：** 优先用随机实验识别因果；无法实验时使用倾向得分匹配、双重差分和固定效应，并明确不成立时不能宣称因果。真实生产数据应先做治理和口径版本化，再进入分层和策略评估。

# 五、项目整体复盘

## 5.1 项目业务目标

项目服务于内容社区平台的创作者供给侧优化，目标不是单纯提高发文量，而是同时改善：

- 新人的持续创作和留存；
- 有效内容供给与流量分配效率；
- 创作者的已结算收益；
- 内容消费体验与负反馈护栏；
- 运营扶持、推荐产品和商业化策略的可验证性。

## 5.2 完整分析链路

```text
业务对齐
  → 明确新人、活跃、停更、曝光/点击/互动/转化口径
  → ODS 保留原始数据
  → DWD 去重、异常标记、缺失分级、可信度控制
  → DWS 创作者生命周期、7/14日留存、首篇分群、三维分层、赛道指标
  → Python 复现指标、分群对比、四张可视化
  → 客观现象与待验证猜想分离
  → 运营、产品和商业化的实验前置策略
  → AB 指标、护栏、风险和扩量条件
```

本项目的关键不是把 SQL 或图表做完，而是把“数据现象—可验证假设—实验指标—风险边界”连接起来。

## 5.3 项目核心收获

1. **口径先于模型。** 新人以首篇有效公开笔记识别，7/14 日留存看再次发布，28 日流失看月度停更，不能混用注册、登录和发布。
2. **DWD 保留原始行。** 硬异常和软异常都以标记存在，DWS 再消费 `is_core_eligible=1`，保留可追溯性。
3. **分层要能被业务解释。** 三维分层使用活跃度、流量效率、变现价值，而不是直接套用 RFM。
4. **相关不等于因果。** 首篇曝光与留存有同向差异，但只能作为实验假设，不能直接作为流量规则。
5. **策略必须带风险。** 流量扶持、任务奖励和商业挂载都可能提高短期指标，却损害复访、内容质量或自然体验，因此需要主指标和护栏同时评估。
6. **商业分析必须尊重数据边界。** 当前只有创作者结算收益，没有成本和商品毛利，不能把 GMV 或创作者收益包装成平台利润。

## 5.4 面试口述：30 秒简短版

“我做了内容社区创作者成长与变现归因项目，基于 2 万创作者和 10 万笔记搭建 ODS-DWD-DWS 指标链路。先统一定义首篇、有效发布、7/14 日留存和结算收益，再用 pandas 复现生命周期、三维分层、赛道和新人分组分析。结果发现 D7 再发文留存只有 2.01%，留存成功组首篇曝光、CTR 和互动表现更高，但这是相关性，不是因果。项目最终把分析转成可 AB 验证的运营和流量假设，并明确成本数据缺失不能判断平台毛利。”

## 5.5 面试口述：2 分钟详细版

“这个项目服务的是一款图文内容社区。业务痛点是新人发几篇后停更、头部集中和变现分散，所以我把问题拆成四层：新人持续发布、流量效率、变现链路和扶持实验。

数据治理上，我保留了 ODS 原始快照，在 DWD 对测试号、内部号、异常笔记、非法时间、漏斗断链和重复上报做标记，不让清洗逻辑散落在 DWS。DWS 只消费可分析记录，产出创作者生命周期、7/14 日留存、首篇表现分群、三维创作者分层和赛道汇总。

结果上，合格新人 12,862 人，D7 再次发布留存为 2.01%，D14 累计为 7.47%。7 天留存成功组的首篇曝光中位数是 3,828，停更组是 355，CTR 和互动率也更高，同时首周发布篇数中位数是 2 对 1。三维分层中低价值流失群体 11,802 人，说明大量创作者在活跃、流量和变现三个维度同时偏弱。赛道方面，旅行流量和收益份额高，家居 CTR 和 D14 留存较高，数码曝光份额和单篇收益较低。

我在报告里刻意把观测和猜想分开：曝光低和停更同向出现，可能受内容质量、赛道和创作者意愿混杂，不能直接说增加曝光就会留存。所以策略全部设计为 AB：运营侧做潜力新人和高流失新人的分层扶持，产品侧做小比例新人探索流量，商业化侧按赛道验证商品匹配。主指标看 D7/D14 和有效发布，护栏看完读、负反馈、质量、退款和收益，同时要求随机分组、固定指标版本和 ITT 分析。

项目的局限也明确：模拟数据、没有成本字段、没有真实实验，因此不能计算平台毛利或宣称因果。后续接真实数据会补事件级曝光、内容质量、成本和实验分组，再用匹配、双重差分或随机实验验证增量。”
