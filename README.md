# resume-projects

## 项目：创作者社区APP创作者成长与变现归因分析
### 项目简介
本项目围绕APP创作者生态开展数据分析，基于用户行为数据搭建ODS-DWD-DWS数仓分层体系，对创作者留存、变现转化等核心指标进行拆解，定位影响创作者成长与变现的关键因素，输出业务洞察与可落地的优化策略，辅助产品运营决策。

### 技术栈
Python、Hive SQL、数据仓库分层（ODS/DWD/DWS）、指标体系搭建、归因分析

### 仓库内容
- Python脚本：数据读取、清洗、预处理、指标计算逻辑
- Hive SQL脚本：分层建表、数据流转、质量校验SQL
- Markdown文档：完整方案设计、数据治理说明、业务复盘与策略复盘
- raw_data：GPT模拟生成的脱敏原始数据集 + 数据字典
- output：分析可视化结果图

### 补充说明
原始数据集为模拟生成的脱敏行为数据，无真实用户信息，已随项目一并上传，整套代码可直接运行复现完整分析流程。
